# محرر EXBIN / EXBIN Editor

محرر أكواد للغة EXBIN يعمل **بدون إنترنت** على كل المنصات: Windows وmacOS وLinux وAndroid وiOS.
محرك EXBIN (نفس شيفرة C) مُترجَم إلى **WebAssembly** ويعمل داخل المتصفح في Web Worker،
فلا حاجة لتثبيت أي شيء ولا لخادم.

## الميزات
**التحرير**
- تلوين الصيغة (كلمات مفتاحية، دوال مدمجة، دوال المشروع، نصوص، تعليقات، أرقام) مع دعم العربية.
- **إكمال تلقائي** ذكي: الكلمات المفتاحية، الدوال المدمجة بتواقيعها ووصفها، القصاصات (`fn` `if` `for` `pcall` `lexer`…)، أسماء الملف الحالي والملفات الأخرى، وطرق الكائنات بعد `.`. (`Ctrl+Space` لإظهاره يدوياً.)
- **توقيع الدالة** أثناء الاستدعاء مع تمييز المعامل الحالي.
- **فحص أخطاء مباشر** أثناء الكتابة (يترجم الكود في Worker منفصل): خط متموّج، رقم السطر أحمر، علامة على التبويب، وتبويب «المشاكل».
- **بحث واستبدال** (حالة الأحرف / كلمة كاملة / تعبير نمطي) مع تمييز كل النتائج، استبدال الكل بخطوة تراجع واحدة.
- تمييز الأقواس المتطابقة والسطر الحالي وتكرارات الكلمة تحت المؤشر.
- إكمال الأقواس والاقتباس، إزاحة ذكية، Backspace ذكي، إخراج `}` تلقائي.
- عمليات الأسطر: تعليق `Ctrl+/`، تكرار `Ctrl+D`، حذف `Ctrl+Shift+K`، نقل `Alt+↑/↓`، إزاحة `Tab`/`Shift+Tab`.
- **تنسيق الكود** `Shift+Alt+F` (إزاحة حسب الأقواس، حذف المسافات الزائدة).
- **مخطط الرموز** (الدوال والمتغيرات العامة) والقفز إليها، و**لوحة الأوامر** `F1` (أوامر، ملفات، `@` رموز، `:` رقم سطر).

**التشغيل**
- تشغيل بـ `Ctrl+Enter` أو `F5`، وزر «إيقاف» يقطع الحلقات اللانهائية.
- **الإدخال القياسي**: اكتب نص `stdin` ليقرأه `input()` سطراً سطراً.
- عرض الـ bytecode (disassembly).
- أخطاء بسطر قابل للنقر (يقفز إلى الملف والسطر الصحيحين، حتى داخل الوحدات).
- **مرجع الدوال** مبحوث بتواقيعها وأوصافها بالعربية، والنقر يُدرج الدالة.

**الملفات والمشروع**
- عدة ملفات في تبويبات (قائمة بالنقر الأيمن/الضغط المطوّل: إعادة تسمية، تكرار، تنزيل، إغلاق)؛ `require("اسم")` تجد الملفات المفتوحة، والمكتبتان `pratt` و`pretty` جاهزتان.
- إعادة فتح الملف المُغلق `Ctrl+Shift+T`، حفظ تلقائي ومكان المؤشر لكل ملف.
- فتح ملفات متعددة أو **سحب وإفلات**، تنزيل ملف، **تنزيل الكل ZIP**، **تصدير/استيراد المشروع** `.exbproj`.
- `read_file` / `write_file` تعمل على نظام ملفات مؤقت في الذاكرة (يُمسح عند كل تشغيل).

**التجربة**
- إعدادات: حجم الخط، عرض الإزاحة، المظهر (تلقائي/فاتح/داكن)، وتشغيل/إيقاف كل ميزة ذكية.
- شريط رموز سريع للهاتف (مع زر الاقتراحات)، وواجهة متجاوبة.
- PWA: قابل للتثبيت ويعمل offline، مع إشعار عند توفر تحديث.

## التشغيل
يعمل أيضاً بالنقر المزدوج على `index.html` مباشرة (وضع مستقل عبر `inline.js` الذي يضمّ المحرك)، لكن الأفضل تقديمه عبر خادم (أي خادم ثابت) ليعمل التثبيت وoffline:

```sh
cd editor && ./serve.sh 8080      # ثم افتح http://localhost:8080
```

انشره كما هو على أي استضافة ثابتة — يجب أن يكون HTTPS ليعمل «التثبيت».

**GitHub Pages:** الملف `.github/workflows/pages.yml` ينشر المجلد تلقائياً عند كل push إلى `main`. فعّله مرة واحدة من Settings ← Pages ← Source: **GitHub Actions**، فيصير الرابط `https://USER.github.io/REPO/`.

## على Android
1. **الأسهل:** افتح الرابط في Chrome ← القائمة ← «تثبيت التطبيق / إضافة إلى الشاشة الرئيسية».
   يعمل بعدها كتطبيق مستقل وبدون إنترنت.
2. **ملف APK (اختياري):** مجلد `android/` فيه إعداد [Capacitor](https://capacitorjs.com):
   ```sh
   cd editor/android
   npm install
   npx cap add android      # مرة واحدة
   npx cap sync
   npx cap open android     # يفتح Android Studio ← Build ← Build APK
   ```
   (يحتاج Node وAndroid Studio. لم يُبنَ APK داخل هذه البيئة.)

## إعادة بناء الملفات المولَّدة
- `exbin.wasm`: `WASI_SYSROOT=/path/to/wasi-sysroot ./wasm/build.sh`
- `data.js` (الأمثلة والمكتبات): `node tools/build-data.mjs`
- `inline.js` (الوضع المستقل من `file://`): `node tools/build-inline.mjs` بعد تغيير `worker.js` أو `data.js` أو `exbin.wasm`.
- عند تعديل أي ملف ارفع `VERSION` في `sw.js` ليتحدّث الكاش.
- مرجع الدوال في `lang.js` مكتوب يدوياً؛ حدّثه عند إضافة دالة مدمجة جديدة في `src/natives.c`.

## قيود معروفة
- الناتج يظهر عند انتهاء التشغيل (المحرك متزامن داخل wasm)، لا أثناءه.
- `args` فارغة دائماً في المحرر.

